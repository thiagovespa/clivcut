# clivcut user guide

Short, task-based pages. New to clivcut? Start with **Getting started**, then jump to whatever you need.

| Page | What you will learn |
|---|---|
| [Getting started](getting-started.md) | Install, create a project, import, the main areas of the window, your first export |
| [Editing on the timeline](editing.md) | Cutting, trimming, tracks, snapping, markers, speed, keyframes, groups and compound clips |
| [Text, captions and stickers](text-and-captions.md) | Titles and styles, highlighted and curved text, shapes, stickers, animations, automatic captions |
| [Audio](audio.md) | Volume and fades, loudness, noise, voice isolation and effects, ducking, voiceover, silences, transcript editing, beat markers, music separation |
| [Color, effects and motion](color-and-effects.md) | Filters and grading, scopes, masks, chroma key, background removal, effects, transitions, stabilization, motion tracking |
| [Exporting](exporting.md) | Video, GPU encoding, transparent video, audio only, still frames, in/out range, render preview, command line |

Two habits make everything easier to find:

- **Ctrl+K** opens the command palette: type what you want ("split", "captions", "beats") and it shows the action and its shortcut.
- The menu under the clivcut logo has **Help → Take the tour** (a one-minute walk through the window) and **Help → What's new**.

All AI features (captions, transcript, voice isolation, music separation, background and object cutout, smooth slow motion, AI voice) run **on your computer**; their models are downloaded once, when you first use them.
